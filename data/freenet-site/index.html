Read by this page's own JavaScript. The contract key is the origin's host, which is what keeps one contract from reading another's storage.

Getting around

  • Type a freenet: address, or paste a whole contract key, into the address bar.
  • A shortened address such as freenet:EqJ5YpEE is completed against the contracts your node knows.
  • The node console shows whether your node is connected, what it holds, and can start or stop it.
  • Settings holds the gateway address, if your node does not listen on the usual port.

About

Northstar is a web browser written from scratch in C, with no upstream browser engine. It speaks freenet: as a first-class URL scheme rather than as a bookmark to a local port, so every contract gets its own origin.

It is the GPL edition of the Nordstjernen project, and this page was published to Freenet with fdev website publish.
